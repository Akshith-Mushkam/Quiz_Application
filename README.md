# Quiz_Application
Quiz Application is a Java-based console application designed to provide an interactive quiz experience. It allows users to answer multiple-choice questions, validates their answers, calculates scores, and displays results. The project demonstrates basic Java concepts such as OOP, classes, methods, loops, and conditional statements.
A simple and interactive **Quiz Application** built using **Java**.  
This project allows users to answer multiple-choice questions and view their final score instantly.

---

## 🚀 Features

- ✅ Multiple-choice quiz system  
- ✅ Questions displayed one by one  
- ✅ Instant score calculation  
- ✅ Beginner-friendly Java project  
- ✅ Built using IntelliJ IDEA  

---

## 🛠️ Tech Stack

- **Language:** Java  
- **IDE:** IntelliJ IDEA  
- **Project Type:** Console-based Quiz App
